## Privacy Policy

This plugin does not collect, retain, or log personal data itself. User prompts,
model inputs, and optional image URLs are transmitted to UCloud ModelVerse for
inference. The API credential is used only to authenticate requests and is not
included in logs or error messages.

For more details, refer to the
[UCloud ModelVerse Privacy Policy](https://www.ucloud-global.com/en/docs/modelverse/private).
